= 為 Nutanix 設定 ONTAP Volume、匯出原則和權限
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
建立並設定 ONTAP 儲存設備 Volume，設定匯出原則，並定義 Nutanix 用於管理 ONTAP 儲存設備的 SVM 角色和服務帳戶。完成這些任務後，您可以將 FlexVol 匯出附加至 Nutanix 叢集，作為虛擬機器工作負載的共享儲存設備。

流程首先建立 ONTAP FlexVol Volume 並設定 NFS 匯出原則。然後，定義所需的 SVM 角色和 REST API 權限，最後將 ONTAP 儲存設備連接到 Nutanix 運算叢集。



[[create-ontap-flexvol-volumes]]
== 建立 ONTAP FlexVol Volume

建立所需的 FlexVol Volume 並套用建議的 ONTAP 設定，以最佳化 Nutanix 工作負載的容量使用率、儲存效率和效能。

.步驟
. 使用以下設定建立 FlexVol Volume：
+
[cols="40,60"]
|===
| 設定 | 組態 


| Volume 保證 | 無（精簡配置） 


| `fractional_reserve` | 0% 


| `snap_reserve` | 0% 


| 自動調整 | 開啟 


| 儲存效率 | 已啟用 


| 自動刪除 | `volume` / `oldest_first` 


| Volume 分層原則 | 僅 Snapshot 快照技術 


| `try_first` | 自動擴充 


| Snapshot 原則 | 無 
|===


[NOTE]
====
* 配置多個 FlexVol Volume 並將它們新增為儲存 Container。
* 建立至少 4 到 8 個 NFSv3 Volume 來存放虛擬機器資料。
* 為 Nutanix 服務或中繼資料 Volume 使用專用 Volume。雖然服務資料可以共享資料 Volume，但建議使用專用 Volume。
* 預設使用 FlexVol 匯出路徑。如果使用 qtree，請在附加儲存 Container 時指定 qtree 匯出路徑。
* 將 Volume 均勻分佈在 ONTAP 節點上，以交替節點的方式放置 Volume，以平衡整個叢集的工作負載配置與資源使用率。


====


[[calculate-the-service-volume-size]]
=== 計算服務 Volume 大小

在計算中繼資料（服務）Volume 的大小時，每個叢集節點至少需要分配 1 TiB 的空間（N × 1 TiB）。例如，一個 8 節點叢集至少需要 8 TiB 的可用容量。

[NOTE]
====
* 為 Nutanix 中繼資料建立單一資源隨需配置的 FlexVol Volume。
* 如果未為服務 Volume 指定專用匯出路徑，則系統會自動使用為叢集服務（中繼資料）Volume 設定的第一個匯出路徑，並將 *Cluster Services* 標籤套用至該路徑。
* 部署後請勿重新命名選定的 FlexVol Volume 或其關聯的匯出路徑。重新命名可能會毀損虛擬機器 I/O 操作並影響工作負載的存取能力。
* 用於服務 Volume 的 FlexVol Volume 可以使用資源隨需配置來進行設定。


====


[[calculate-the-data-volume-size]]
=== 計算資料 Volume 大小

資料 Volume 規模調整與資料存放區規模調整類似。根據預期的虛擬機器數量、容量需求和預期成長，來調整儲存 Container Volume 的規模。規劃足夠的可用空間，以容納 VM 資源配置、快照和營運例行成本，同時將工作負載分配到多個 Volume 上，以支援擴充性和均衡的資源使用率。



[[configure-ontap-export-policies]]
== 設定 ONTAP 匯出原則

設定匯出原則，以便只有 Nutanix CVM 可以存取 NFS Volume。

*資料 Volume*

. 建立 Volume 層級的匯出原則，以允許 CVM IP 位址或子網路範圍。
. 設定以下規則：
+
.. 唯讀規則(`rorule`）： `sys`
.. 讀寫規則(`rwrule`）： `sys`
.. 超級使用者： `sys`


. 如果使用 qtree，則為每個 qtree 建立一個具有相同權限的專用匯出原則規則。


*服務或中繼資料 Volume*

. 建立 Volume 層級的匯出原則，以允許 CVM IP 位址或子網路範圍。
. 設定以下規則：
+
.. 唯讀規則(`rorule`）： `sys`
.. 讀寫規則(`rwrule`）： `sys`
.. 超級使用者： `sys`




[NOTE]
====
* 所有 ONTAP NFS 匯出都應僅允許從 Nutanix CVM IP 位址或指定的 CVM 子網路存取。
* 使用 Prism API 或 `ncli` 尋找 CVM 主機 IP 位址清單，以更新匯出原則。


====


[[configure-ontap-roles-and-permissions]]
== 設定 ONTAP 角色和權限

為了將 ONTAP 儲存設備連接到 Nutanix 運算叢集，Nutanix 使用 ONTAP REST API 進行控制平面操作（虛擬機器配置、複製、快照和儲存管理），並使用 NFSv3 作為資料路徑。

建立一個權限最低的 ONTAP 角色，這樣您就不需要使用該 ONTAP `admin` 角色在 Nutanix 純運算叢集中執行操作。這些最低權限角色是 ONTAP 儲存設備端 SVM 層級所必需的。

[NOTE]
====
* 使用 ONTAP NFS 的預設組態設定。
* 您也可以使用  `vsadmin` 角色。


====


[[minimum-rest-api-permissions]]
=== 最低 REST API 權限

建立自訂 ONTAP SVM 角色，並賦予其所需的最低 REST API 權限，以啟用 Nutanix 儲存設備探索、配置、複製和管理操作。

[cols="35,15,50"]
|===
| REST API 端點 | 存取 | 目的 


| `/api/cluster` | 唯讀 | 叢集驗證和版本驗證 


| `/api/cluster/jobs` | 唯讀 | 監控非同步儲存設備操作 


| `/api/network/ip/interfaces` | 唯讀 | 探索 ONTAP 資料 LIF 


| `/api/storage/file/clone` | 讀取/建立 | 虛擬機器複製、Snapshot 快照技術和備份作業 


| `/api/storage/volumes` | 唯讀 | Volume 探索與管理 


| `/api/storage/volumes/*/files` | 完全存取 | 建立、修改、讀取和刪除 Nutanix 管理的檔案 
|===


[[configure-the-service-account]]
=== 設定服務帳戶

您可以使用 ONTAP System Manager 或 ONTAP CLI 建立角色和使用者。

[role="tabbed-block"]
====
.System Manager
--
.步驟
. 在 SVM 層級建立自訂角色。
+
.. 選擇 *儲存設備 > Storage VM > _指定的 SVM_ > 設定 > 使用者與角色*。
.. 選擇 *使用者和角色* 旁的箭頭圖示（→）。
.. 在 *角色* 下，選取 *+新增*。
.. 定義角色規則，然後點選 *Save* 。
+
image:nutanix-storage-001.png["ONTAP System Manager 角色屬性頁面列出 Nutanix 角色的 REST API 路徑和存取層級"]



. 將角色對應到 Nutanix 管理員使用者。
+
.. 在 *使用者和角色* 頁面上，於 *使用者* 下，選取 *+新增*。
.. 選取所需的使用者名稱，然後從 *角色* 下拉式選單中選取您在上一個步驟中建立的角色。
.. 對於使用者登入方式，請選擇 *HTTP*。
.. 按一下 *Save* 。
+
image:nutanix-storage-002.png["ONTAP System Manager 使用者和角色頁面顯示對應至自訂角色的 Nutanix 使用者"]

+
image:nutanix-storage-003.png["ONTAP System Manager 使用者和角色頁面顯示 SVM 的使用者和角色存取層級"]





--
.CLI
--
.步驟
. 執行下列命令來建立角色。將  `ntnx-svm` 與  `nim-ntnx-role` 取代為您的 SVM 與角色名稱。
+
[source, cli]
----
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/cluster" -access readonly
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/cluster/jobs" -access readonly
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/network/ip/interfaces" -access readonly
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/storage/file/clone" -access read_create
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/storage/volumes" -access readonly
security login rest-role create -vserver ntnx-svm -role nim-ntnx-role -api "/api/storage/volumes/*/files" -access all
----
. 建立使用者並將其對應至角色。
+
[source, cli]
----
security login create -vserver ntnx-svm -user-or-group-name nim-ntnx-user -application http -authentication-method password -role nim-ntnx-role
----


--
====

NOTE: 將 ONTAP 陣列新增至 Nutanix 叢集時，需要 ONTAP 服務帳戶的使用者名稱和密碼。在 Prism Element 或 Prism Central 中設定 ONTAP 儲存設備 SVM 時，請使用此使用者。
