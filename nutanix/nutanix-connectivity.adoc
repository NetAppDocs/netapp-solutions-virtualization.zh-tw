= 準備部署搭配 ONTAP 儲存設備的 Nutanix Cloud Platform
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
審查將 Nutanix AHV 純運算主機連接到 ONTAP 儲存設備的先決條件和建議的網路架構。此設計可讓您獨立於運算擴充儲存容量和效能，因此無需僅為了擴充儲存設備而新增 Nutanix 節點。

此設計在 Nutanix AHV 僅運算主機與 ONTAP 儲存設備控制器之間使用專用的儲存網路。儲存設備流量透過專用虛擬交換器（vswitch1）和外部儲存設備 VLAN，與管理和應用程式流量是隔離的。ONTAP 透過專用 SVM 資料 LIF 提供 NFSv3 儲存設備服務，而 SVM 管理 LIF 則與 REST API 搭配使用，以進行儲存設備管理與整合。

為了提高彈性和效能，Nutanix 純運算主機和 ONTAP 控制器在備援網路路徑上使用 LACP（作用中 / 作用中）。如果 LACP 無法使用，採用 MAC 綁定的作用中 / 作用中可在虛擬交換器階層提供負載平衡。儲存流量應位於專用的非路由 VLAN 上，而管理、即時移轉、災難恢復複寫和應用程式流量則繼續使用標準路由網路。



[[prerequisites]]
== 先決條件

在將 ONTAP 儲存設備與 Nutanix 雲端基礎架構整合之前，請確保滿足以下要求。

*Nutanix 叢集*

執行 AHV 的 Nutanix 叢集已部署且運作中，並符合下列需求：

* 至少三個節點。
* 運算節點符合 Nutanix 對 CPU、記憶體容量、連網和開機裝置的最低要求。如需詳細資訊，請參閱最低運算要求。
* 硬體和軟體列於對應的 Nutanix 相容性矩陣。請參閱link:https://portal.nutanix.com/page/compatibility-interoperability-matrix/platform-compatibility/compute-platforms["運算平台相容性與互通性矩陣"^]。


*NetApp ONTAP 儲存設備*

NetApp ONTAP 儲存設備已部署並設定，啟用了 NFS 服務，並符合下列需求：

* 支援的 ONTAP 平台：AFF A 系列（All Flash）、AFF C 系列（All Flash）和 FAS（混合快閃）。
* ONTAP 執行支援的版本：9.15.1P18 或更新版本、9.16.1P16 或更新版本、9.17.1P8 或更新版本、9.18.1P4 或更新版本，或 9.19.1P2 或更新版本。
* ONTAP One 授權。
* ONTAP 儲存設備虛擬機器（SVM）已設定為提供儲存設備給 Nutanix 運算叢集。
* 一個或多個 FlexVol Volume 會匯出為 NFS 共享。Nutanix 叢集會裝載 NFS 匯出，並將其作為工作負載的共享儲存設備。
* NetApp 強烈建議使用介面群組作為 NFS LIF 的主連接埠。如需詳細資訊，請參閱 link:https://docs.netapp.com/us-en/ontap/networking/combine_physical_ports_to_create_interface_groups.html["合併實體連接埠以建立 ONTAP 介面群組"^]。


*網路*

* 專用儲存網路最低支援 10 GbE。建議使用 25 GbE 或更高規格。
* 儲存設備流量有獨立的介面。
* 在支援的儲存網路中，巨型訊框（MTU 9000）的設定保持一致。


[NOTE]
====
* 使用專用的虛擬交換器來處理 ONTAP 儲存設備流量，並設定 MTU 為 9000 位元組（巨型訊框）。
* 為 ONTAP 私有連網啟用網路分段後，便無法停用。停用網路分段會導致儲存設備私有 IP 無法連線，並可能導致關鍵的叢集服務故障。


====


[[network-architecture]]
== 網路架構

下圖顯示 Nutanix AHV 節點與 ONTAP 叢集之間的連線。

image:nutanix-connectivity-001.png["網路圖顯示一個具有 vswitch0 和 vswitch1 的 Nutanix AHV 節點，透過兩個外部交換器連接至 ONTAP 9 叢集"]

下表描述每個網路元件、其組態及其用途。

[cols="25,45,30"]
|===
| 元件 | 組態 | 目的 


| Nutanix 運算節點 | 用於管理和使用者虛擬機器網路（路由 VLAN）以及儲存網路（非路由 VLAN）的綁定網路卡。如果無法使用綁定網路卡，請為虛擬交換器使用作用中/作用中上行連結。 | 提供網路備援，同時隔離管理、虛擬機器和儲存設備流量。 


| ONTAP 儲存設備控制器 | SVM 管理 LIF 和 SVM 資料 LIF。盡可能使用介面群組來實現容錯能力和負載平衡。 | 管理 LIF 用於 ONTAP 管理。資料 LIF 為 Nutanix 叢集提供 NFSv3 儲存設備存取。 


| 管理和用戶虛擬機器網路（路由 VLAN） | Prism 管理、CVM 流量、即時移轉和複寫流量 | 承載叢集管理和虛擬機器流量。 


| 內部儲存網路（非路由） | CVM 間通訊、AHV 服務、叢集節點間流量 | 用於儲存設備和叢集服務的專用網路。與使用者流量隔離。 


| 外部儲存網路（非路由 VLAN） | AHV/CVMs 與 ONTAP 之間的 NFSv3 儲存設備流量 | 提供對 ONTAP 儲存設備的低延遲、高效能存取。 


| vswitch0 | Nutanix 管理、應用程式流量、即時移轉和複寫 | 用於管理和虛擬機器連網的主虛擬交換器。 


| vswitch1 | 專用的 NFSv3 儲存設備流量。至少兩個實體上行連結。建議使用 LACP（作用中/作用中）。MTU 9000。 | 專用儲存設備交換器，可為 ONTAP 連線提供最佳效能、彈性和流量隔離。 
|===


[[high-level-deployment-steps]]
== 高階部署步驟

完成以下高階步驟，以準備 ONTAP、設定儲存網路並將 Nutanix 主機連接到 ONTAP 儲存設備。

. 部署和設定 ONTAP。
+
.. 請參閱 link:https://docs.netapp.com/us-en/ontap/quick-start.html["ONTAP 快速入門"^]。
.. 盡可能建立介面群組。請參閱 link:https://docs.netapp.com/us-en/ontap/networking/combine_physical_ports_to_create_interface_groups.html["合併實體連接埠以建立 ONTAP 介面群組"^]。
.. 為 ONTAP 網路建立 SVM。請參閱 link:https://docs.netapp.com/us-en/ontap/networking/create_svms.html["為 ONTAP 網路建立 SVM"^]。
.. 建立用於管理和 NFS 資料的 ONTAP LIF。請參閱 link:https://docs.netapp.com/us-en/ontap/networking/create_a_lif.html["創建ONTAP LIF"^]。
.. 使用 ONTAP System Manager 新增 Volume。該 Volume 必須使用 UNIX 安全樣式來提供 NFSv3 資料。請參閱 link:https://docs.netapp.com/us-en/ontap/task_admin_add_a_volume.html["使用 ONTAP System Manager 新增 Volume"^] 和 link:https://docs.netapp.com/us-en/ontap/nfs-admin/create-volumes-specified-junction-task.html["建立具有指定交會點的 ONTAP NAS Volume"^]。
.. 設定匯出原則以允許從 Nutanix 僅運算主機存取。請參閱 link:https://docs.netapp.com/us-en/ontap/nfs-admin/export-policies-client-access-volumes-concept.html["匯出原則如何控制用戶端對 ONTAP NFS Volume 或 qtree 的存取"^]。


. 設定儲存網路。
+
.. 為 NFS 儲存設備流量建立一個專用的非路由 VLAN。請參閱 link:https://docs.netapp.com/us-en/ontap/networking/configure_vlans_over_physical_ports.html["建立專用的非路由 VLAN"^]。
.. 設定備援交換器基礎架構。
.. 啟用端點對端點巨型訊框（MTU 9000）。如需 ONTAP 的相關資訊，請參閱 link:https://docs.netapp.com/us-en/ontap/networking/change_the_mtu_value_for_ports_in_a_broadcast_domain.html["變更 ONTAP 廣播網域中連接埠的 MTU 值"^]。


. 配置 Nutanix 主機並將其連接至 ONTAP。
+
.. 驗證與 ONTAP NFS 資料 LIF 的連線。
.. 驗證負載平衡和路徑備援。


. 建立一個專用儲存設備虛擬交換器。
+
.. 在 Nutanix AHV 上建立 vswitch1。
.. 至少分配兩個專用的實體網路卡。
.. 在支援的情況下設定 LACP（作用中/作用中）。


. 驗證韌性。
+
.. 測試儲存設備路徑故障轉移。
.. 確認 AHV 能夠在連結或交換器故障期間自動重新路由儲存設備流量，而不會影響正在運作的虛擬機器。




此架構為 Nutanix 環境提供高效能、高可用度的儲存網路，同時允許運算和儲存資源獨立擴充。儲存成長可透過 ONTAP 擴充來滿足，無需額外的 Nutanix 純運算節點，從而在維持企業級效能和可用度的同時降低基礎架構成本。
