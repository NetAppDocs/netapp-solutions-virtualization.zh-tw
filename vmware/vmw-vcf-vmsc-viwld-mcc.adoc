= 使用 MetroCluster 為 VCF 工作負載網域設定延伸叢集

:nofooter: 
:icons: font
:linkattrs:

[role="lead"]
在此使用案例中，我們將概述使用 ONTAP MetroCluster （以 FC、iSCSI、NVMe-oF、NFSv3 或 NFSv4.1 作為主要資料存放區）為 VMware Cloud Foundation (VCF) 工作負載網域設定延展式叢集的程序。VCF 可根據您的需求，提供部署選項的靈活度。VCF Ops 工具可用於部署新的 VCF 工作負載網域，或將現有的 vSphere 環境匯入至 VCF 工作負載網域。在本文件中，我們將重點放在 MetroCluster 部分，並根據部署步驟指向其他文件。

image:vmw-vcf-vmsc-viwld-mcc-001.png["VCF 工作負載域與 vMSC，width=500"]



[[introduction]]
== 介紹

在此解決方案中，我們將示範如何實作以 ONTAP MetroCluster 作為主要資料儲存庫的延伸 VCF 工作負載網域。MetroCluster 允許為 ONTAP 叢集上執行的所有工作負載部署高可用度解決方案。如果需要部署針對特定工作負載的高可用度解決方案，請考慮使用 SnapMirror 主動同步（SAN 和 NAS）。SnapMirror 主動同步（SAN）在一致性群組層級運作，而 SnapMirror 主動同步（NAS）則在 SVM 層級運作。如需詳細資訊，請參閱 link:vmw-vcf-vmsc-viwld-smas.html["使用 SnapMirror Active Sync（SAN 和 NAS）為 VCF 工作負載網域設定延伸叢集"]。



[[prerequisites]]
== 先決條件

此場景需要以下組件和配置：

* 支援的ONTAP MetroCluster配置
* 已設定慣用儲存傳輸協定的儲存虛擬機器 （SVM）。
* 已建立邏輯介面 （LIF） 來承載儲存設備流量，並且與 SVM 相關聯。




[[high-level-overview]]
== 概要

MetroCluster 為彙總層級的工作負載提供高可用度解決方案。SVM 將在 MetroCluster 的其中一個故障網域上處於作用中狀態。

[[deployment-steps-for-greenfield-vcf-workload-domain-with-metrocluster]]
== 全新 VCF 工作負載網域與 MetroCluster 的部署步驟

對於全新部署（不包含任何現有 VCF 元件的新部署），請使用 VCF Ops 工具部署工作負載域。此方案支援 FC 上的 VMFS 和 NFSv3。

若為 FC 上的 VMFS，請參閱 link:vmw-vcf-viwld-principal-fc.html["VCF 工作負載域，以 ONTAP 上的 FC 型 VMFS 資料存放區作為主要儲存設備"] 以取得更多資訊。若為 NFSv3，請參閱 link:vmw-vcf-viwld-principal-nfs.html["VCF 工作負載網域，以 ONTAP 上的 NFSv3 資料存放區作為主要儲存設備"] 以取得更多資訊。



[[deployment-steps-for-brownfield-vcf-workload-domain-with-metrocluster]]
== 棕地 VCF 工作負載網域與 MetroCluster 的部署步驟

棕地部署是指您擁有現有的 vSphere 環境，並且想要將其匯入為 VCF 工作負載域的情境。

對於 iSCSI、NVMe-oF 和 NFSv4.1，需要先設定 vCenter（最好使用 ONTAP tools），然後再使用 VCF Ops 工具將其匯入為工作負載域。如需詳細資訊，請參閱 link:https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/building-your-private-cloud-infrastructure/working-with-workload-domains/import-an-existing-vcenter-to-create-a-workload-domain.html["匯入現有 vCenter 以建立工作負載網域"]。
