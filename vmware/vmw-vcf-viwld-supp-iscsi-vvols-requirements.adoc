= 工作負載網域中 iSCSI vVols 的部署需求
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
請檢閱建議的連網設計與基礎架構需求，以便在 VMware Cloud Foundation 工作負載網域中部署 iSCSI vVols。您需要一個已完整設定的 ONTAP AFF 或 ASA 儲存系統、一個已完成的 VCF 管理網域，以及一個現有的工作負載網域。



[[infrastructure-requirements]]
== 基礎設施需求

確保以下組件和配置已到位。

* ONTAP AFF或ASA儲存系統，其乙太網路交換器上的實體資料連接埠專用於儲存流量。
* VCF管理域部署完成，可以存取vSphere客戶端。
* 工作負載域已預先部署。




[[recommended-iscsi-network-design]]
== 推薦的 iSCSI 網路設計

您應該為 iSCSI 配置完全冗餘的網路設計。下圖說明了冗餘配置的範例。它為儲存系統、交換器、網路適配器和主機系統提供容錯功能。有關更多信息，請參閱NetApplink:https://docs.netapp.com/us-en/ontap/san-config/index.html["SAN 配置參考"^] 。

image:vmware-vcf-asa-074.png["iSCSI網路設計"]

{nbsp}

對於跨多路徑的多路徑和故障轉移，請在單獨的乙太網路中為 iSCSI 配置中的所有 SVM 每個儲存節點建立至少兩個 LIF。


NOTE: 如果在相同 IP 網路上設定了多個 VMkernel 介面卡，請在 ESXi 主機上使用軟體 iSCSI 連接埠繫結，以確保介面卡之間的負載平衡。請參閱知識庫文章link:https://knowledge.broadcom.com/external/article?legacyId=2038869["在 vSphere 主機中使用軟體 iSCSI 連接埠繫結的注意事項"^]。
