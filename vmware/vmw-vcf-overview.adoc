[role="lead"]
NetApp ONTAP 與 VMware Cloud Foundation （VCF） 整合，交付統一化儲存解決方案，支援區塊、檔案和物件協定。ONTAP 的多租戶功能使組織能夠整合工作負載並簡化管理，同時提供企業級資料保護和可用度。本文件提供 VCF 總覽，以及如何使用 NetApp ONTAP 來增強 VCF 環境中的儲存功能。



[[introduction]]
== 介紹

VCF 使組織能夠輕鬆部署和管理私有雲環境。它開箱即用地提供虛擬機器、Kubernetes、容器和網路以服務形式，並支援擴展，透過自助服務入口網站以目錄項目的形式提供其他服務。透過在 VCF 中將 NetApp ONTAP 作為儲存解決方案，組織可以在管理工作負載時實現更高的靈活度、擴充性和效率。



[[introduction-to-netapp-ontap]]
== NetApp ONTAP簡介

NetApp ONTAP 是一款全面的資料管理軟體，可在廣泛的產品線中提供進階儲存設備功能。ONTAP 可作為軟體定義儲存設備使用，也可透過主流雲端供應商以第一方服務的形式提供，並可作為 NetApp ASA（區塊優化型解耦儲存）、AFX（非結構化資料解耦儲存）、AFF 和 FAS（統一儲存）平台的儲存作業系統。ONTAP 為 VMware 虛擬化在內的各種使用案例提供高效能和低延遲，且不會造成資料孤島。與在運算中建立虛擬機器類似，ONTAP 允許建立儲存設備虛擬機器 （SVM），這些 SVM 可用於建立和管理儲存資源。ONTAP 提供統一化儲存解決方案，支援多種通訊協定，包括 NFS、SMB、iSCSI、FC、NVMe/TCP、NVMe/FC 和 NVMe/RDMA。這種靈活度使企業能夠整合工作負載並簡化管理，同時提供企業級資料保護和可用度。



[[introduction-to-vmware-cloud-foundation]]
== VMware Cloud Foundation 簡介

VMware Cloud Foundation (VCF) 使組織能夠建立虛擬私有雲，以服務形式使用虛擬機器、Kubernetes 叢集、容器、網路和儲存設備，無論是用於 AI 工作負載、DevOps 還是傳統的虛擬機器型工作負載。

VCF 可部署到全新環境中，或將現有 vSphere 環境擴充為完整的私有雲。一組運算主機構成一個 vSphere 叢集，一組 vSphere 叢集構成一個 VCF 網域，一組 VCF 網域構成一個 VCF 執行個體。一個機組由一個或多個 VCF 執行個體組成。VCF 私有雲環境由一個或多個機組建立而成。作業與自動化在機組層級進行處理，而 VCF 執行個體則是部署單元。

vSphere 命名空間用於設定工作負載的資源限制。vSphere Zone 是 vSphere 叢集的集合，可用於為在該區域內執行的工作負載提供高可用度和災難恢復能力。

image:vmware-vcf-overview-components.png["VMware 雲端基礎元件"]

在 VCF Automation 中，區域是來自一個或多個 VCF 網域的 vSphere 可用區集合，這些可用區共用相同的 NSX 基礎架構。組織是來自一個或多個區域的使用者和資源的邏輯分組。組織可細分為多個專案，每個專案都有自己的傳輸閘道和外部連線。專案包含一個或多個命名空間，可用於為在專案中執行的工作負載提供隔離和資源分配。

命名空間是專案內資源分配的基本單元。每個命名空間都會對應到一個虛擬私有雲（VPC），可用於為在該命名空間中執行的工作負載提供隔離和資源分配。

命名空間可透過專用 VPC 或共享的 VPC 建立。專用 VPC 是專用於單一命名空間的 VPC，而共享的 VPC 則是可供多個命名空間使用的 VPC。子網路在部署工作負載的 VPC 內建立。

儲存設備由在 vCenter 中定義的儲存原則型管理 （SPBM） 原則使用。SPBM 可透過一組規則建立，這些規則定義了工作負載的儲存設備需求。資料儲存通常會被標記，並用於建立符合不同工作負載特定需求的儲存設備原則。

需要親和性和反親和性規則的工作負載由基礎架構策略進行管理，這些策略使用 vCenter 運算策略來定義工作負載在特定主機或叢集上的放置位置。基礎架構策略可用於確保工作負載根據其需求放置在特定的主機或叢集上。



[[vcf-domains]]
== VCF 域

域是 VCF 內的基礎構造，可以將資源組織成不同的、獨立的群組。域有助於更有效地組織基礎設施，確保資源得到有效利用。每個網域都部署有自己的運算、網路和儲存元素。

image:vmware-vcf-overview-domains.png["VMware 雲端域"]

具有 VCF 的域主要有兩種類型：

* *管理網域* – 管理網域包含負責 VCF 環境核心功能的元件。這些元件處理資源配置、監控、維護等關鍵任務，並整合了第三方外掛，例如 NetApp ONTAP Tools for VMware。管理網域可以使用 VCF Installer Appliance 進行部署，以確保遵循最佳實務；或者，也可以將現有的 vCenter 環境轉換為 VCF 管理網域。
* *工作負載域* – 工作負載域旨在作為資源池，專用於滿足特定的維運需求、工作負載或組織。工作負載域可透過 OPS Manager 輕鬆部署，進而協助自動化一系列複雜任務。在 VCF 環境中最多可配置 24 個工作負載域，每個工作負載域代表一個應用程式就緒的基礎架構單元。每個工作負載域都擁有自己的 NSX 基礎架構，或共享現有基礎架構，這取決於其為單一區域部署或多區域部署。




[[storage-with-vcf]]
== 使用 VCF 存儲

域功能的核心是它們消耗的儲存空間。雖然 VCF 包含用於超融合用例的基於 CPU 核心的 vSAN 容量，但它也支援廣泛的外部儲存解決方案。對於在現有儲存陣列上投入大量資金或需要支援超出 vSAN 能力範圍的協議的企業來說，這種靈活性至關重要。  VMware 透過 VCF 支援多種儲存類型。

VCF 儲存主要有兩種類型：

* *主儲存設備* – 此儲存設備類型會在新 VCF 網域的初始部署（Day 0）或現有 vCenter 的整合或匯入過程中自動佈建。VCF 安裝程式支援在全新部署中使用 VSAN、FC 上的 VMFS 和 NFS，而其他支援的儲存設備類型（包括 iSCSI 上的 VMFS 和 NVMe-oF）則可在現有 vCenter 的整合或匯入過程中作為主儲存設備使用。ONTAP Tools for VMware vSphere 僅可用於現有 vCenter 的整合或匯入，以部署 VCF 網域的主儲存設備。任何在額外叢集部署或網域擴充過程中建立的資料存放區均視為主儲存設備。主儲存設備用於主機 VCF 管理元件（包括 vCenter、NSX Manager 和 SDDC Manager），以及網域內執行的工作負載。
* *補充儲存設備* – 補充儲存設備是指在 VCF 網域初始部署之後，或現有 vCenter 環境融合或匯入之後配置的任何資料儲存。可以使用 ONTAP Tools for VMware vSphere 為 VCF 網域部署資料儲存來建立補充儲存設備。建立補充儲存設備是為了滿足額外的容量需求、效能要求，或支援需要不同儲存設備特性的特定工作負載。此外，還可以建立補充儲存設備來建立高可用度的擴充叢集。


*支援VCF儲存類型*

[cols="25%, 25%, 50%"]
|===


| *網域類型* | *主要存儲* | *補充存放* 


| 管理域 | vSAN FC NFS 3 NFS 4.1 ^2^ iSCSI ^2^ NVMe/TCP ^2^ NVMe/FC ^2^ NVMe/RDMA ^2^ | vVols（FC、iSCSI 或 NFS）^1^ FC NFS 3 NFS 4.1 iSCSI NVMe/TCP NVMe/FC NVMe/RDMA 


| 工作負載域 | vSAN vVols（FC、iSCSI 或 NFS）^1^ FC NFS 3 NFS 4.1 ^2^ iSCSI ^2^ NVMe/TCP ^2^ NVMe/FC ^2^ NVMe/RDMA ^2^ | vVols（FC、iSCSI 或 NFS）^1^ FC NFS 3 NFS 4.1 iSCSI NVMe/TCP NVMe/FC NVMe/RDMA 
|===

NOTE: ^1^ vVol 支援在 vSphere 環境中已過時。^2^ 使用 Converge 或匯入選項



[[why-ontap-for-vcf]]
== 為什麼ONTAP適用於 VCF

除了涉及投資保護和多協定支援的用例之外，還有許多其他原因可以利用 VCF 工作負載域中的外部共用儲存。可以假設為工作負載域配置的儲存只是託管虛擬機器和容器的儲存庫。然而，組織的需求往往超出許可容量的能力，並需要企業儲存。  ONTAP提供的儲存分配給 VCF 內的網域，易於部署並提供面向未來的共用儲存解決方案。

image:why-ontap-for-vmware-002.png["為什麼ONTAP適用於 VCF"]

有關下面列出的 VMware VCF 的主要ONTAP優勢的更多信息，請參閱link:vmw-getting-started-overview.html#why-ontap-for-vmware["為什麼選擇ONTAP for VMware"]。

* 第一天以及擴展過程中的靈活性
* 將儲存任務卸載到ONTAP
* 一流的儲存效率
* 企業級資料可用性
* 高效率的備份和復原作業
* 整體業務連續性能力

[[summary]]
== 總結

ONTAP提供了一個滿足所有工作負載需求的平台，提供客製化的區塊儲存解決方案和統一的產品，以可靠、安全的方式為虛擬機器和應用程式提供更快的結果。 ONTAP採用先進的資料縮減和行動技術，最大限度地減少資料中心佔用空間，同時確保企業級可用性，使關鍵工作負載保持在線。此外，AWS、Azure 和 Google 支援NetApp驅動的外部存儲，以增強 VMware 基於雲端的叢集中的 vSAN 存儲，作為其 VMware-in-the-Cloud 產品的一部分。總體而言，NetApp 的卓越功能使其成為 VMware Cloud Foundation 部署的更有效選擇。
