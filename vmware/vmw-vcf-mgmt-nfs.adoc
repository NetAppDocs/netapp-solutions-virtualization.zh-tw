= 將 vCenter 伺服器執行個體融合至具有 NFS 資料存放區的 VCF 管理網域的部署工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
將具有 NetApp ONTAP NFS 資料儲存庫的現有 vSphere 叢集融合至 VMware Cloud Foundation 管理網域。您將審查組態需求、部署 ONTAP tools 並資源配置 NFS 資料儲存庫，然後使用 VCF Installer Tool 來驗證並使用現有元件、部署所需的新元件，以及設定平台。

如果 ONTAP NFS 4.1 資料存放區要用作 VCF 管理網域的主儲存設備，則此工作流程也適用。

有關融合式程序的總覽，請參閱 VMware 文件： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["將現有虛擬基礎架構融合至 VCF"]。
