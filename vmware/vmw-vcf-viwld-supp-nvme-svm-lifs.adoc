= 在 VMware Cloud Foundation 工作負載網域中為 NVMe/TCP 資料儲存區建立 SVM 和 LIF 以及 NVMe 命名空間
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
建立具有多個邏輯介面 (LIF) 的儲存虛擬機器 (SVM)，為 VMware Cloud Foundation 工作負載域提供 NVMe 連線。此過程總結了設定支援 NVMe/TCP 的 SVM 和 LIF 以及建立 NVMe 命名空間。



[[step-1-create-the-svms-and-lifs]]
== 步驟 1：建立 SVM 和 LIF

完成以下步驟，為 NVMe/TCP 流量建立具有多個 LIF 的 SVM。

若要為現有 SVM 新增新的 LIF，請參閱ONTAP文件：link:https://docs.netapp.com/us-en/ontap/networking/create_a_lif.html["創建ONTAP LIF"^] 。

.步驟
. 從ONTAP系統管理員中，導覽至左側選單中的 *儲存虛擬機器*，然後按一下 *+ 新增*。
+
.顯示範例
[%collapsible]
====
image:vmware-vcf-asa-001.png["點擊“+新增”開始建立 SVM"]

====
. 在“新增儲存虛擬機器”精靈中，輸入 SVM 的“名稱”，選擇“IP 空間”，然後在“存取協定”下按一下“NVMe”標籤並勾選“啟用 NVMe/TCP”複選框。
+
.顯示範例
[%collapsible]
====
image:vmware-vcf-asa-075.png["新增儲存虛擬機器精靈 - 啟用 NVMe/TCP"]

====
. 在 *網路介面* 部分中，輸入第一個 LIF 的 *IP 位址*、*子網路遮罩* 和 *廣播域和連接埠*。對於後續 LIF，您可以使用單獨的設置，也可以啟用複選框以在所有剩餘 LIF 中使用通用設定。
+

NOTE: 對於跨多路徑的多路徑和故障轉移，請在單獨的乙太網路中為 NVMe/TCP 配置中的所有 SVM 每個儲存節點建立至少兩個 LIF。

. 選擇是否啟用儲存虛擬機器管理帳戶（適用於多租用戶環境），然後按一下「*儲存*」以建立 SVM。
+
.顯示範例
[%collapsible]
====
image:vmware-vcf-asa-004.png["啟用 SVM 帳戶並完成"]

====




[[step-2-create-the-nvme-namespace]]
== 步驟 2：建立 NVMe 命名空間

NVMe 命名空間類似 iSCSi 或 FC 的 LUN。您必須先建立 NVMe 命名空間，然後才能從 vSphere Client 部署 VMFS 資料儲存區。

若要建立 NVMe 命名空間，請從叢集中的每台 vSphere 主機取得 NVMe 限定名稱 （NQN）。ONTAP 使用 NQN 為命名空間提供存取控制。

.步驟
. 透過 SSH 與叢集中的 vSphere 主機建立工作階段，以取得其 NQN。使用以下 CLI 命令：
+
[source, cli]
----
esxcli nvme info get
----
+
應顯示類似以下範例的輸出：

+
[source, cli]
----
Host NQN: nqn.2014-08.com.netapp.sddc:nvme:vcf-wkld-esx01
----
. 記錄叢集中每個 vSphere 主機的 NQN。
. 從ONTAP系統管理員中，導覽至左側選單中的 *NVMe 命名空間*，然後按一下 *+ 新增* 開始。
+
.顯示範例
[%collapsible]
====
image:vmware-vcf-asa-093.png["按一下「+新增」以建立 NVMe 命名空間"]

====
. 在「新增 NVMe 命名空間」頁面上，填寫名稱前綴、要建立的命名空間數量、命名空間的大小以及將存取命名空間的主機作業系統。
. 在 *主機 NQN* 部分，建立一個以逗號分隔的列表，列出先前從將要存取命名空間的 vSphere 主機收集的 NQN。
. 按一下「更多選項」以配置其他項目，例如快照保護策略。
. 最後，按一下「儲存」以建立 NVMe 命名空間。
+
.顯示範例
[%collapsible]
====
image:vmware-vcf-asa-093.png["按一下「+新增」以建立 NVMe 命名空間"]

====
