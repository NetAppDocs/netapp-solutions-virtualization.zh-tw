= 將 vCenter 伺服器執行個體融合至具有 VMFS 資料存放區的 VCF 管理網域的部署工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
將具有 NetApp ONTAP VMFS 資料儲存庫的現有 vSphere 叢集融合至 VMware Cloud Foundation 管理網域。您將審查組態需求、部署 ONTAP tools 並資源配置 VMFS 資料儲存庫，然後使用 VCF Installer 工具來驗證及使用現有元件、部署所需的新元件並設定平台。

此工作流程也用於將任何受支援的 VMFS 資料儲存作為 VCF 管理網域的主儲存設備使用。

有關轉換過程的總覽，請參閱 VMware 文件： https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/deployment/converging-your-existing-vsphere-infrastructure-to-a-vcf-or-vvf-platform-.html["將現有虛擬基礎架構融合至 VCF"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:vmw-vcf-mgmt-vmfs-requirements.html["查看配置要求"]
[role="quick-margin-para"]
審查使用 VMFS 資料儲存區將 vCenter 伺服器執行個體融合至 VCF 管理網域的關鍵需求。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:vmw-vcf-mgmt-vmfs-deploy.html["部署 ONTAP tools 並資源配置受支援的 VMFS 資料存放區"]
[role="quick-margin-para"]
部署 ONTAP tools for VMware vSphere，並資源配置受支援的 VMFS 資料儲存。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:vmw-vcf-mgmt-vmfs-converge.html["將 vSphere 叢集融合至 VCF 管理網域"]
[role="quick-margin-para"]
使用 VCF 安裝程式工具來驗證、重複使用現有元件並部署構成 VCF 管理網域的新元件。
