[role="lead"]
在此使用案例中，我們將概述使用 ONTAP MetroCluster 並以 FC、iSCSI、NVMe-oF、NFSv3 或 NFSv4.1 作為主要資料儲存庫，來為 VMware Cloud Foundation (VCF) 管理網域設定延伸叢集的程序。VCF 根據您的需求，在部署選項上提供靈活度。VCF Installer 工具可用於部署新的 VCF 管理網域，或將現有的 vSphere 環境轉換為 VCF 管理網域。在本文件中，我們將著重於 MetroCluster 部分，並根據部署步驟指向其他文件。

image:vmw-vcf-vmsc-mgmt-mcc-001.png["帶有 vMSC 的 VCF 管理域,寬度=500"]



[[introduction]]
== 介紹

本解決方案將示範如何以 ONTAP MetroCluster 作為主要資料儲存區來實作擴充 VCF 管理網域。MetroCluster 可為在 ONTAP 叢集上執行的所有工作負載部署高可用度解決方案。如果需要針對特定工作負載部署高可用度解決方案，請考慮使用 SnapMirror 作用中同步（SAN 和 NAS）。SnapMirror 作用中同步（SAN）在一致性群組層級運作，而 SnapMirror 作用中同步（NAS）在 SVM 層級運作。如需更多資訊，請參閱 link:vmw-vcf-vmsc-mgmt-smas.html["使用 SnapMirror Active Sync（SAN 和 NAS）為 VCF 管理網域設定延伸叢集"]。



[[prerequisites]]
== 先決條件

此場景需要以下組件和配置：

* 支援的ONTAP MetroCluster配置
* 已設定慣用儲存傳輸協定的儲存虛擬機器 （SVM）。
* 已建立邏輯介面 （LIF） 來承載儲存設備流量，並且與 SVM 相關聯。




[[high-level-overview]]
== 概要

MetroCluster 為彙總層級的工作負載提供高可用度解決方案。SVM 將在 MetroCluster 的其中一個故障網域上處於作用中狀態。

[[deployment-steps-for-greenfield-vcf-management-domain-with-metrocluster]]
== 使用 MetroCluster 的全新 VCF 管理網域部署步驟

對於全新部署（不包含任何現有 VCF 元件的新部署），請使用 VCF 安裝程式工具來部署管理網域。此方案支援 FC 上的 VMFS 和 NFSv3。

有關 FC 上的 VMFS，請參閱 link:vmw-vcf-mgmt-principal-fc.html["VCF 管理網域，以 ONTAP 上的 FC 型 VMFS 資料存放區作為主要儲存設備"] 以取得更多資訊。有關 NFSv3，請參閱 link:vmw-vcf-mgmt-principal-nfs.html["VCF 管理網域，以 ONTAP 上的 NFSv3 資料儲存作為主要儲存設備"] 以取得更多資訊。



[[deployment-steps-for-brownfield-vcf-management-domain-with-metrocluster]]
== 棕地 VCF 管理網域搭配 MetroCluster 的部署步驟

棕地部署是指您擁有現有的 vSphere 環境，並希望將其整合為 VCF 管理網域的情境。

對於 iSCSI、NVMe-oF 和 NFSv4.1，需要使用 vCenter 進行設定（最好使用 ONTAP tools），然後使用 VCF 安裝程式工具將其合併到管理網域中。如需更多資訊，請參閱 link:vmw-vcf-mgmt-vmfs.html["vCenter 與 VMFS 資料儲存的融合"] 和 link:vmw-vcf-mgmt-nfs.html["vCenter 與 NFS 資料存放區的融合"]。
