= 在 ONTAP 上使用 NFS 資料存放區作為 VCF 工作負載網域的主儲存設備
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
本使用案例概述如何在 ONTAP 上設定 NFS 資料存放區，使其成為 VMware Cloud Foundation （VCF） 工作負載網域的主儲存設備解決方案。本程序總結了所需的元件、組態步驟和部署流程。



[[benefits-of-nfs]]
== NFS 的優勢

*簡單易用：*NFS 設定和管理簡單，使其成為需要快速簡單的文件共享環境的絕佳選擇。

*可擴展性*：ONTAP 的架構允許 NFS 有效擴展，從而無需對基礎架構進行重大更改即可支援不斷增長的資料需求。

*靈活性*：NFS 支援廣泛的應用程式和工作負載，使其適用於各種用例，包括虛擬化環境。



[[scenario-overview]]
== 場景概述

此場景涵蓋以下進階步驟：

* 為 NFS 流量建立具有邏輯介面 (LIF) 的儲存虛擬機器 (SVM)
* 驗證ONTAP儲存虛擬機器 (SVM) 的網路以及是否存在用於承載 NFS 流量的邏輯介面 (LIF)。
* 建立匯出原則，允許 vSphere 主機存取 NFS Volume。
* 在ONTAP儲存系統上建立 NFS 磁碟區。
* 在 SDDC Manager 中為 NFS 和 vMotion 流量建立網路池。
* 在 vCenter 中委任主機，以供 VCF 工作負載網域使用。
* 在 VCF Ops 中使用 NFS 資料儲存區作為主儲存設備部署 VCF 工作負載域。
* 確保叢集"映像"包含適用於 VMware VAAI 的 NetApp NFS 插件。



NOTE: 此解決方案適用於支援 NFS 儲存設備的 ONTAP 平台，包括 NetApp AFF、AFX 和 FAS。



[[prerequisites]]
== 先決條件

此場景中使用以下元件和配置：

* NetApp AFF、AFX 或 FAS 儲存系統，並設定儲存虛擬機器 （SVM） 以允許 NFS 流量。
* 已在 IP 網路上建立用於承載 NFS 流量並與 SVM 關聯的邏輯介面 (LIF)。
* VCF 管理域部署已完成，VCF Operations Manager 介面可存取。
* 至少有 2 台 vSphere 主機設定為在 VCF 管理網路上進行通訊。
* 為此目的建立的 VLAN 或網路段上為 vMotion 和 NFS 儲存流量保留的 IP 位址。



NOTE: 部署 VCF 工作負載域時，VCF 會驗證與 NFS 伺服器的連線性。此驗證在新增任何其他具有 NFS IP 位址的 vmkernel 介面卡之前，會使用 vSphere 主機上的管理介面卡來完成。因此，必須確保以下兩種情況之一：1） 管理網路可路由至 NFS 伺服器；或 2） 已將管理網路的 LIF 新增至託管 NFS 資料儲存 Volume 的 SVM，以確保驗證能夠順利進行。

有關配置ONTAP儲存系統的信息，請參閱link:https://docs.netapp.com/us-en/ontap["ONTAP 9 文件"]中心。

有關設定 VCF 的資訊，請參閱 link:https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1.html["VMware 雲端基礎文檔"]。

有關在 vSphere 群集中使用 NFS 的更多信息，請參閱link:vmw-vvf-overview.html["適用於 vSphere 8 的 NFS v3 參考指南"]。

[[deployment-steps]]
== 部署步驟

若要部署以 NFSv3 資料儲存區為主儲存設備的 VCF 工作負載網域，請完成下列步驟：

.驗證ONTAP SVM 的網路連接
[%collapsible%open]
====
確認已為將在 ONTAP 儲存設備叢集和工作負載網域之間承載 NFS 流量的網路建立所需的邏輯介面。

. 在 ONTAP System Manager 中，導覽至左側選單中的「儲存虛擬機器」，然後按一下要用於 NFS 流量的 SVM。在「概覽」標籤上的「網路介面」下，按一下「NFS」標籤上方的數字。在清單中確認所需的 LIF IP 位址已列出。
+
image:vmw-vcf-viwld-principal-nfs-001.png["驗證 SVM 的 NFS LIF"]



或者，使用以下命令從ONTAP CLI 驗證與 SVM 關聯的 LIF：

[source, cli]
----
network interface show -vserver <SVM_NAME>
----
. 驗證 vSphere 主機是否可以與 ONTAP NFS 伺服器通訊。透過 SSH 登入 vSphere 主機並 ping SVM LIF：


[source, cli]
----
vmkping <IP Address>
----

NOTE: 部署工作負載域時，VCF 會驗證與 NFS 伺服器的連線性。此驗證在新增任何其他具有 NFS IP 位址的 vmkernel 介面卡之前，會使用 vSphere 主機上的管理介面卡來完成。因此，必須確保下列其中一種情況：1） 管理網路可路由至 NFS 伺服器；或 2） 已將管理網路的 LIF 新增至裝載 NFS 資料儲存 Volume 的 SVM，以確保驗證能夠順利進行。

====
.建立共用 NFS 磁碟區的匯出策略
[%collapsible%open]
====
在ONTAP系統管理員中建立導出策略來定義 NFS 磁碟區的存取控制。

. 在ONTAP系統管理員中，按一下左側選單中的“*儲存虛擬機器*”，然後從清單中選擇一個 SVM。
. 在*設定*標籤上找到*匯出策略*並點擊箭頭進行存取。
+
image:vmw-vcf-viwld-principal-nfs-002.png["訪問出口政策"]

+
{nbsp}

. 點擊「新增」後，將開啟「*新匯出原則*」視窗。為原則命名，點選「*新增規則*」按鈕，然後點選「*+新增*」按鈕開始新增規則。
+
image:vmw-vcf-viwld-principal-nfs-003.png["新的出口政策"]

+
{nbsp}

. 填入您要在規則中包含的 IP 位址、IP 位址範圍或網路。取消勾選 *SMB/CIFS* 和 *FlexCache®* 方塊，並在下方進行存取詳細資料的選擇。選取 UNIX 方塊即足以供 vSphere 主機存取。
+
image:vmw-vcf-viwld-principal-nfs-004.png["儲存新規則"]

+

NOTE: 部署工作負載域時，VCF 會驗證與 NFS 伺服器的連線。此驗證透過 vSphere 主機上的管理介面卡完成，在新增任何其他具有 NFS IP 位址的 vmkernel 介面卡之前進行。因此，必須確保匯出原則包含 VCF 管理網路，才能使驗證順利進行。

. 輸入所有規則後，按一下「儲存」按鈕儲存新的匯出策略。
. 或者，您可以在ONTAP CLI 中建立匯出策略和規則。請參閱ONTAP文件中建立匯出策略和新增規則的步驟。
+
** 使用ONTAP CLIlink:https://docs.netapp.com/us-en/ontap/nfs-config/create-export-policy-task.html["建立導出策略"] 。
** 使用ONTAP CLIlink:https://docs.netapp.com/us-en/ontap/nfs-config/add-rule-export-policy-task.html["在匯出策略中新增規則"] 。




====
.建立 NFS 卷
[%collapsible%open]
====
在ONTAP儲存系統上建立一個 NFS 卷，用作工作負載域部署中的資料儲存。

. 從ONTAP系統管理員導覽至左側選單中的 *儲存 > 磁碟區*，然後按一下 *+新增* 以建立新磁碟區。
+
image:vmw-vcf-viwld-principal-nfs-005.png["新增磁碟區"]

+
{nbsp}

. 新增磁碟區的名稱，填寫所需的容量並選擇將託管該磁碟區的儲存虛擬機器。按一下“*更多選項*”繼續。
+
image:vmw-vcf-viwld-principal-nfs-006.png["添加卷詳細信息"]

+
{nbsp}

. 在存取權限下，選擇匯出策略，其中包括 VCF 管理網路或 IP 位址和 NFS 網路 IP 位址，這些位址將用於驗證 NFS 伺服器和 NFS 流量。
+
image:vmw-vcf-viwld-principal-nfs-007.png["添加卷詳細信息"]

+
+ {nbsp}

+

NOTE: 部署 VCF 工作負載域時，VCF 會驗證與 NFS 伺服器的連線性。此驗證在新增任何其他具有 NFS IP 位址的 vmkernel 介面卡之前，會使用 vSphere 主機上的管理介面卡來完成。因此，必須確保以下兩種情況之一：1） 管理網路可路由至 NFS 伺服器；或 2） 已將管理網路的 LIF 新增至託管 NFS 資料儲存 Volume 的 SVM，以確保驗證能夠順利進行。

. 或者，也可以在 ONTAP CLI 中建立 NFS Volume。如需更多資訊，請參閱 ONTAP 命令文件中的 link:https://docs.netapp.com/us-en/ontap-cli/volume-create.html["volume create"] 命令。


====


[[vcf-workload-domain-default-cluster]]
=== VCF 工作負載域 - 預設叢集

管理網域啟動並運作後，即可建立 VCF 工作負載域：

* 使用 VCF Ops UI。vSphere 主機已在 vCenter 中完成部署，網路資源池已設定。使用 System Manager 或 ONTAP API 將 NFS Volume 匯出至 vSphere 主機。
* 將現有 vSphere 環境匯入為新的工作負載域。ONTAP tools for VMware vSphere 或 System Manager 或 ONTAP API 可用於將 NFSv3 或 NFS4.1 資料存放區部署至 vSphere 叢集。




[[vcf-workload-domain-additional-cluster]]
=== VCF 工作負載域 - 附加叢集

若要使用額外的叢集擴充工作負載域，請參閱 https://techdocs.broadcom.com/us/en/vmware-cis/vcf/vcf-9-0-and-later/9-1/building-your-private-cloud-infrastructure/working-with-workload-domains/expand-a-workload-domain/add-a-cluster-to-a-workload-domain-using-the-sddc-manager-ui.html["將 SDDC 叢集新增至 VCF 網域"]。

從高層級來看，為工作負載網域新增額外叢集的步驟如下：* 確保主機已完成部署，且網路資源池已在 vCenter 中完成設定。* NFS Volume 已在 ONTAP 儲存系統上完成資源配置，並匯出至額外叢集中的主機。* NFS Volume 已掛載至額外叢集中的其中一台 vSphere 主機。* 在 vCenter 的工作負載網域上建立新的 SDDC 叢集，並依照精靈指示將額外叢集新增至工作負載網域。
