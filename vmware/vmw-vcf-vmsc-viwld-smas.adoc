= 使用 SnapMirror 作用中同步（SAN 和 NAS）為工作負載網域設定延伸叢集
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
在此使用案例中，我們將概述使用 SnapMirror 作用中同步與 ONTAP tools for VMware vSphere 為工作負載網域設定延伸叢集的程序（ONTAP tools 10.6 支援 FC 與 iSCSI）。ONTAP 支援適用於 SAN（搭配 iSCSI、Fibre Channel 及 NVMe over Fabrics）與 NAS（NFSv3 與 NFSv4.1）的 SnapMirror 作用中同步。

image:vmw-vcf-vmsc-viwld-smas-001.png["使用 SnapMirror 主動同步的 VCF Stretch 叢集"]

SAN 支援均勻和非均勻擴展叢集組態。若為 NAS，則採用 ONTAP 9.19.1 的主動被動式組態。

[NOTE]
====
主機鄰近性設定與多重路徑組態結合使用，以確保儲存設備流量選擇最佳路徑。對於 SCSI，主機鄰近性設定在 igroup 上設定；對於 NVMe-oF，主機鄰近性設定在子系統上設定。例如，在統一主機存取組態中，主機可以存取延伸叢集中的兩個儲存系統。在多重路徑組態中，最佳路徑和非最佳路徑會根據主機鄰近性設定進行配置。

====


[[scenario-overview]]
== 場景概述

VCF 工作負載域上的資料儲存可以透過 SnapMirror 作用中同步進行保護，從而提供擴展叢集解決方案。對於 SAN，保護在資料儲存層級（一致性群組）啟用；對於 NAS，保護在 SVM 層級啟用。



[[prerequisites]]
== 先決條件

.工作負載域上的主存儲
[%collapsible%open]
====
工作負載域可以透過匯入或使用 VCF Ops 工具建立。

. 使用任何受支援的協定建立工作負載網域。
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-vcenter.html["將工作負載域 vCenter 註冊到ONTAP工具管理器以部署 vCenter 插件"]
. link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-storage-backend.html["在ONTAP工具上註冊儲存系統"]
. 對於 iSCSI 和 FC 資料存放區，請參閱link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/protect/protect-multiple-ds.html["使用 ONTAP tools 保護 vSphere 資料存放區"]
. 對於 NVMe-oF 和 NFS 資料存放區，請參閱下方的影片示範，以了解使用 SnapMirror 主動同步保護工作負載網域上的資料存放區的步驟。


====
.工作負載域上的補充存儲
[%collapsible%open]
====
工作負載域啟動並運作後，即可使用 ONTAP tools 建立和保護其他資料儲存區。有關 SnapMirror 作用中同步的更多詳細資訊，請參閱 https://docs.netapp.com/us-en/ontap/snapmirror-active-sync/index.html#benefits["了解 ONTAP SnapMirror 主動同步"]


TIP: 使用 ONTAP tools 10.6 及更新版本，您可以使用 SnapMirror active sync 來保護工作負載網域上的資料存放區。請參閱下方的影片示範，瞭解使用 SnapMirror active sync 保護工作負載網域上資料存放區的步驟。

====
