= 將 FC 型 VMFS 資料存放區新增為工作負載網域的補充儲存設備
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
本使用案例概述如何使用 Fibre Channel （FC）設定 VMFS 資料存放區，作為 VMware Cloud Foundation （VCF）工作負載網域的補充儲存設備。此程序概述如何部署 ONTAP Tools for VMware vSphere、註冊工作負載 vCenter 伺服器、定義儲存設備後端及配置 FC 資料存放區。

.開始之前
確保以下組件和配置已到位。

* 具有連接到 FC 交換器的 FC 連接埠的ONTAP AFF或ASA儲存系統。
* 使用 FC LIF 建立的 SVM。
* 帶有 FC HBA 的 vSphere 連接到 FC 交換器。
* 在 FC 交換器上設定單一啟動器-目標分割區。


[NOTE]
====
* 在區域配置中使用 SVM FC 邏輯接口，而不是ONTAP系統上的實體 FC 連接埠。
* 對 FC LUN 使用多路徑。


====
.步驟
. 請按照 ONTAP tools for VMware vSphere 說明文件中的指示來註冊工作負載網域 vCenter：link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-vcenter.html["註冊工作負載 vCenter"]。
+
註冊工作負載網域 vCenter 伺服器即可啟用該 vCenter 外掛程式。

. 依照適用於ONTAP tools for VMware vSphere文件中的說明，使用 vSphere 用戶端介面新增儲存後端：link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/add-storage-backend.html["使用 vSphere 用戶端介面定義儲存後端"] 。
+
新增儲存後端可讓您加入ONTAP叢集。

. 依照適用於ONTAP tools for VMware vSphere文件中的說明，在光纖通道 (FC) 上設定 VMFS：link:https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/configure/create-datastore.html["在 FC 上配置 VMFS"] 。
