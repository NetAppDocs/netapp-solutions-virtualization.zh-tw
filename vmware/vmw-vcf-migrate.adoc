= 了解如何將具有現有資料儲存區的 vSphere 環境融合至 VCF 管理網域
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
任何受支援的 vSphere 環境都可以作為 VCF 私有雲環境的一部分。它可以融合至 VCF 管理網域，也可以作為工作負載網域匯入。此解決方案示範了當叢集轉換為 VCF 管理網域時，vSphere 中現有的 VMFS 或 NFS 資料存放區如何成為主要儲存設備。



[[solution-overview]]
== 解決方案概述

此解決方案示範了當叢集融合式至 VCF 管理網域時，vSphere 中現有的 VMFS 或 NFS 資料存放區如何成為主要儲存設備。

此流程受益於 ONTAP 儲存設備的穩健性和靈活度，從而確保無縫的資料存取和管理。透過融合流程建立 VCF 管理網域後，管理員可以有效率地將其他 vSphere 環境（包括同時使用 VMFS 和 NFS 資料儲存的環境）匯入 VCF 生態系統。

這種整合不僅提高了資源利用率，還簡化了私有雲基礎架構的管理，確保了平穩過渡，並最大限度地減少了對現有工作負載的干擾。



[[architecture-overview]]
== 架構概述

ONTAP工具的架構與 VMware 環境無縫集成，利用包含ONTAP工具服務、vSphere 外掛程式和 REST API 的模組化可擴充框架實現高效的儲存管理、自動化和資料保護。

ONTAP tools for VMware vSphere可以安裝在 HA 或非 HA 配置中。
