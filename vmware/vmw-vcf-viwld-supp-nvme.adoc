= 在工作負載域中新增 vVols NVMe 資料存放區作為補充儲存設備的部署工作流程
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
開始為 VMware Cloud Foundation (VCF) 工作負載域新增 NVMe/TCP vVols 資料儲存作為補充儲存設備。您將審查部署要求、設定支援 NVMe/TCP 的 SVM 和 LIF、設定 vSphere 主機連網，並部署 NVMe/TCP vVol 資料儲存。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["一"]link:vmw-vcf-viwld-supp-nvme-requirements.html["查看部署要求"]
[role="quick-margin-para"]
審查在 VMware Cloud Foundation 工作負載域中部署 NVMe/TCP 資料儲存的要求。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["二"]link:vmw-vcf-viwld-supp-nvme-svm-lifs.html["建立 SVM 和 LIF 以及 NVMe 命名空間"]
[role="quick-margin-para"]
為 NVMe/TCP 流量建立具有邏輯介面和 NVMe 命名空間的儲存虛擬機器。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["三"]link:vmw-vcf-viwld-supp-nvme-network.html["設定網路"]
[role="quick-margin-para"]
在 vSphere 主機上為 VCF 工作負載網域建立分散式連接埠群組和 vmkernel 介面卡。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["四"]link:vmw-vcf-viwld-supp-nvme-storage.html["配置儲存"]
[role="quick-margin-para"]
部署 NVMe/TCP 資料儲存。
